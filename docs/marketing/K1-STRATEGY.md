## 1. Radical Transparency

*Weaponise honesty in a market full of vague claims.*

1. **"The Frame Budget"** — Publish exact per-frame timing breakdown as infographic
2. **"We Tested at 110 FPS and It Was Not Good Enough"** — The RMT regression story with before/after data
3. **"The 30-Minute Soak"** — Publish raw soak test logs with commit hashes
4. **"The Kill List"** — Document abandoned approaches (6 failed WiFi STA attempts)
5. **"Open Benchmark Protocol"** — Standardised methodology + capture tool, dare competitors
6. **"64 Bins, Not Vibes"** — Side-by-side of K1's signal inventory vs competitors' "audio reactive"
7. **"The Pattern Cage Problem"** — Deep product thinking as content (bounded state spaces in effects)
8. **"The Heap Never Lies"** — Public telemetry dashboard with live K1 metrics
9. **"The 2ms Ceiling"** — Recurring series on non-negotiable engineering constraints
10. **"Commit-Level Traceability"** — Every marketing claim links to a specific git commit
11. **"The Bisect"** — Publish how you debug (Stage 1 cherry-pick bisect story)
12. **"Don't Trust Us, Measure Us"** — Ship verification mode, encourage users to run it
13. **"The Changelog as Content"** — Publish full CHANGELOG.md as a living website page
14. **"The Architecture Decision Record"** — Publish ADRs with full rationale (AP-only WiFi, Goertzel over FFT)
15. **"The Oscilloscope Post"** — Raw hardware proof (dual-strip WS2812 traces with timing annotations)
