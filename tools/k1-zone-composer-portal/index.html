Per-Zone Effect Parameters

Phase 1 · D-3
gated on D-1 keystone hardware validation command-matrix §4

Per-zone effect parameters allow each zone to mutate its own effect's parameters without affecting other zones running the same effectId. Requires D-1 instance pool; without it, parameter writes silently corrupt cross-zone state. Spike 1 prototype landed (commit 2fe2f289); production switch behind K1_ZONE_INSTANCE_POOL_ENABLED compile gate (default off).
